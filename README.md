# INKLUR (DoPilot)

### Say it. Get it done.

Inklur is an early-stage AI agent designed to turn natural-language instructions into completed digital work.

Instead of manually opening different tools and performing repetitive steps, users can tell DoPilot what they want in plain language, and Inklur can understand the instruction and execute the task using connected digital tools and APIs.

## 🚀 Current Prototype

Inklur is currently an early working prototype.

The prototype can:
- Understand natural-language user instructions
- Use Google Gemini API for AI-powered understanding
- Execute simple digital tasks
- Send emails through an email API
- Connect AI reasoning with real actions

### Example

A user can tell INKLUR:

> "Send an email to Rahul saying that the meeting has been postponed."

Inklur processes the instruction and performs the email task.

## 🎯 Vision

The long-term goal of Inklur is to build an AI execution platform where users can describe a desired outcome instead of learning how to operate many different websites, applications, and digital tools.

Inklur aims to move AI from simply answering questions to actually completing digital work.
